# Warioware Game

A Warioware game by Charlie for the Stardance Mission

![Image of Level One](https://github.com/Miningsleuth/Warioware-Game/blob/main/warioware-game/assets/Screenshot2026-08-15120146.png?raw=true)


## Features
- 2 Minigames: Platformer & Clicker
- Win & Death Screens
- Life tracking

## Attribution
Thanks to the Warioware Game making guide on Stardance

## How to Play
- Access game at itch.io
- Start game by pressing Start
- Exit by choosing quit in the menu
- Before each level, a scene shows your lives and time till next level
- You have a set amount of time to complete each level
- If your lives run out, you lose! Complete both levels to win!
- Enjoy!

Created for a mission on Stardance by Hackclub
